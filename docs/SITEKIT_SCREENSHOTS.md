# SiteKit Studio screenshots

These are full-page Playwright captures of the Components and Projects Studio views using local fixture data.

They are **static visual previews**, not captures of a running Umbraco instance. The environment currently has no available SQL Server service and Docker Desktop's Linux engine is unavailable, so these screenshots verify page layout and fixture-driven interactions only. The banner in each screenshot marks this limitation.

- `sitekit-components-static-preview.png`: component catalogue, definition editor, schema/layout controls, variants, and preview.
- `sitekit-projects-static-preview.png`: project list, component placement, project-local appearance controls, and preview.

Reproducible HTML fixture pages are included next to the PNGs. Do not use them as a substitute for authenticated end-to-end verification against a running Umbraco application.
